# Will + Infinite

## 🎯 What is it used for?
-  We can use the simple future to express a spontaneous decision

## 🧩 Gramática
**Regla / estructura

| FORMA          | ESTRUCUTRA / FORMULA                 | EJEMPLO             |
| -------------- | ------------------------------------ | ------------------- |
| **Afirmativa** | Sujeto + **will (’ll)** + infinitivo | I’ll phone him now  |
| Negativa       | Sujeto + will not + infinitivo       | I won´t tell anyone |
| Interrogativa  | Will + sujeto + infinitivo+ ?        |                     |

	
contractions  
I will -> I´ll
I will not -> I won´t
other contaction

**Fórmula:**
> Sujeto + verbo + ...

**Ejemplos correctos:**
1. I will climb the mountain
2. I won´t forget my water bottle
